Code for "On the maximality conjecture for quantum permutation groups" (Claude and Teo), state of 31 October 2026.
Python 3 with numpy and scipy.  Each script explains its usage in its first lines (run it without arguments, or with
"test", to see it).  Every script writes a log file next to itself (<name>out.txt, or an output folder).  File names
carry no digits; numbers inside generated file names are written in unary ("x" * k) or in words.

Conventions
- Exact ranks are computed modulo primes p < 2^20 after a random compression (rows R C mod p, float64 products, exact
  below 2^53); the rank can only drop, so a Catalan output is a proof.  Gram-matrix ranks modulo two large primes are
  used where the entries are small integers.
- Primes: 1048573 (duals, sol, doubling, tyson, kitty, tiger), 1048261 = 1 mod 60 (twists, twistpu), 1048433 = 1 mod 8
  (level 8), 2147483647 and 1000000007 (Gram ranks).
- Laptop jobs (tyson, kitty, tiger, evander, nine) run 7-8 hours, stop by themselves and are resumable.
- The level-7 and level-8 data files produced on the laptops (levelseven/resulta.json, halfturn and leveleight results,
  tysonout, tigerout) are kept as they were produced; the big .npz working files are regenerated by the scripts.
